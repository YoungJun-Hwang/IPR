IPR 실제 자료 수집 (Chrome / Edge 확장)

1. ZIP을 풀고 chrome://extensions 또는 edge://extensions 에서 개발자 모드를 켭니다.
2. '압축해제된 확장 프로그램 로드'로 이 폴더를 선택합니다.
3. 정상적으로 접근 가능한 쿠팡 상품 상세 페이지를 열고 판매자 정보 창을 표시합니다.
4. 확장 아이콘 → 현재 상품 정보 읽기 → 판매자 정보 확인 → 이 상품·대표 사진을 로컬에 저장.
5. 여러 판매자·서로 다른 상품을 같은 방식으로 모은 뒤 JSON을 내려받습니다.
6. IPR 웹사이트의 '실제 결과 파일 열기'에서 JSON을 선택합니다. 실제 이미지에서 중복을 계산합니다.

로그인·CAPTCHA·접근 제한을 우회하지 않습니다. 자동으로 다른 페이지나 API를 방문하지 않습니다.
공개 상품·상호·명시적인 사업자 유형·대표 사진만 수집합니다. 쿠키, 계정 토큰, 연락처, 로그인 정보는 수집하지 않습니다.
사진 저장 시 쿠팡 CDN 접근 권한을 사용자에게 요청합니다. 쿠키 없이 요청하며 리다이렉트·거절은 실패로 처리합니다.
화면에 유형이 없으면 확인 불가로 둡니다. 사업자번호나 이름으로 유형을 추측하지 않습니다.
사용자가 직접 수정한 분류는 사용자 입력 출처로 표시됩니다. 수집한 사진을 서버나 공개 GitHub 저장소에 올리지 않습니다.
자료는 확장의 IndexedDB에 저장됩니다. 삭제 버튼으로 이 도구의 저장 자료만 지울 수 있습니다.
