권리 기준 이미지

찾고 싶은 원본 상품·디자인 이미지를 등록하세요.

동일 파일과 pHash 기반 시각적 유사성을 검사합니다. 이미지 구조가 비슷한 상품을 찾는 방식이며 상표·캐릭터의 의미나 법적 권리 범위를 인식하지 않습니다.
쿠팡 우선 검토: 공개 정보에서 개인사업자로 명시된 판매자만 기본 목록에 표시합니다. 서로 다른 상품 카탈로그 사이의 동일 파일·동일 픽셀 사진을 집계합니다. 같은 쿠팡 카탈로그의 사진 공유는 별도로 표시하며 우선순위 집계에서 제외합니다. 현재 쿠팡 실수집은 검증되지 않았습니다. 정식 공급사 사진 공유도 가능하므로 중복 수치는 위반 확률이 아닙니다.

기준 이미지 없이 중복 사진으로 검토 순서를 정하고, 확인된 항목을 판매자별로 모아보세요.
