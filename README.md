# IPR · 권리 검토 워크스페이스

상품 URL과 사용자가 등록한 권리 자료를 비교해 **검토할 근거**를 모으는 한국어 웹앱 초안입니다. 침해 여부를 판정하지 않습니다.

## 쇼핑몰 자동 점검

쇼핑몰 주소와 권리 기준 이미지를 등록하면 카테고리별 상품 이미지를 수집하고, 시각적 유사도가 높은 검토 후보를 목록으로 추립니다. Python 서버에서 실제 점검하며 GitHub Pages에서는 가상 결과 화면을 체험합니다. 지원 범위·실행·제한은 [CATALOG_SCANNING.md](CATALOG_SCANNING.md)를 참고하세요.

## GitHub Pages에서 보기

서버 없이 사용하는 웹 시연 버전을 추가했습니다. 샘플·직접 입력 비교와 브라우저별 기록 저장을 지원합니다. 배포와 사용 안내는 [GITHUB_PAGES.md](GITHUB_PAGES.md)를 참고하세요. 상품 URL 자동 수집과 이미지 비교는 이 정적 버전에서 지원하지 않습니다.

## 실행

Python 3.12 이상을 사용합니다.

```bash
cd /workspace/IPR
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

이 클라우드 환경에서는 이미 준비된 `/workspace/.ipr-venv/bin/python`을 사용해도 됩니다. 웹 화면은 `/`, 서버 상태 확인은 `/api/health`, API 문서는 `/docs`에 있습니다. 서버는 기본적으로 로컬 인터페이스에서 실행합니다.

## 사용 흐름

1. 상품 URL을 입력합니다. 수집이 차단되거나 동적 페이지라면 상품 설명을 직접 입력합니다. 이 경우 URL 방문 없이 입력한 내용만 분석합니다.
2. 브랜드명, 원본 문구, 원본 이미지 중 하나 이상을 등록합니다. 등록번호는 선택 항목이며 기록용입니다.
3. 분석 결과에서 일치 문구와 이미지 파일 동일 여부를 확인합니다.
4. 검토 상태와 의견을 저장하고 JSON으로 내보냅니다. `샘플로 둘러보기`는 네트워크 요청 없이 가상 자료로 전체 흐름을 보여줍니다. 샘플 기록도 저장되며 실제 분석과 구분됩니다.

## 개별 상품 비교의 분석 범위

- 브랜드명: 공백·대소문자 정규화 후 부분 문자열 일치
- 원본 문구: 12자 이상 문장 단위의 정규화된 전체 문구 포함 여부
- 이미지: HTML에서 발견한 최대 3개 이미지와 원본 파일의 SHA-256 비교. 동일 바이트 파일만 검출하며 시각적 유사도·OCR은 지원하지 않음
- 공개 정적 HTML의 제목·텍스트 추출. JavaScript 실행, 로그인, 차단 우회, 쇼핑몰 자동 검색은 지원하지 않음
- 직접 연결에서는 DNS 결과의 사설·루프백·링크 로컬 주소를 차단하고 검증된 IP에 연결. 프록시 연결은 아래의 운영자 승인 도메인으로 제한. 리다이렉트마다 경로를 검증하며 비표준 포트와 인증 포함 URL을 차단하고 HTTPS 인증서 검증을 유지
- 개별 응답과 업로드 이미지는 최대 2MB. 네트워크 연결·읽기 타임아웃은 12초

일치가 정당한 사용일 수 있고, 일치 근거가 없어도 침해가 없다는 뜻은 아닙니다. 권리 등록정보 조회, 문서/PDF 해석, 법률 판단, AI 추론 기능은 아직 구현하지 않았습니다.

## 클라우드 프록시와 수집 도메인

이 클라우드에서는 직접 DNS 조회가 제한되어 플랫폼이 제공한 `HTTPS_PROXY`/`HTTP_PROXY`를 사용해야 합니다. 서버 실행 시 운영자가 공개 수집 대상의 **정확한 호스트명**을 `IPR_PROXY_ALLOWED_HOSTS`에 쉼표로 구분해 등록합니다. 프록시 주소나 인증 값은 코드·문서에 복사하지 않습니다.

```bash
cd /workspace/IPR
IPR_PROXY_ALLOWED_HOSTS=github.com /workspace/.ipr-venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`github.com`은 실제 HTTPS 수집 검증에 사용한 예시입니다. 실제 상품 URL과 이미지 CDN의 호스트명을 이 목록 및 클라우드 환경의 네트워크 허용 목록에 추가해야 합니다. 와일드카드는 지원하지 않습니다. 허용하지 않은 호스트는 프록시로 보내지 않으며, 직접 연결에 필요한 공개 DNS 검증이 실패하면 직접 입력 방식으로 안내합니다.

프록시 모드에서는 원격 DNS 해석을 프록시에 위임하므로, 승인된 도메인은 운영자가 신뢰하는 공개 서비스여야 합니다. 임의 사용자가 이 환경 변수를 수정하도록 허용하지 마세요. 직접 연결 모드는 검증된 IP를 고정해 DNS 재바인딩을 방지합니다. 샘플 분석과 직접 입력 분석에는 외부 수집 도메인이 필요 없습니다.

## 저장과 운영 범위

SQLite 파일은 `.data/reviews.sqlite3`에 생성되며 Git에서 제외됩니다. `IPR_DB_PATH`로 위치를 바꿀 수 있습니다. 분석 텍스트·출처·일치 근거·검토 의견을 저장하며 원본 이미지 바이너리는 저장하지 않습니다. 최근 100건이 기록 화면에 표시됩니다. 프로세스를 재시작해도 같은 DB를 사용하면 기록이 유지됩니다.

인증·사용자별 데이터 분리·요청 제한은 없는 로컬 단일 사용자 초안입니다. 공개 서비스로 배포하기 전에는 인증, 접근 제어, 보관·삭제 정책, 요청 크기·속도 제한 및 수집 대상 사이트의 이용 조건을 검토해야 합니다. 상품 URL 수집 시 해당 사이트에는 서버의 요청이 전달됩니다. 외부 AI로 자료를 전송하지 않습니다.

## 검증

```bash
cd /workspace/IPR
/workspace/.ipr-venv/bin/python -m pytest -q
node --check app/static/app.js
```

테스트는 임시 DB와 모의 상품 응답으로 자료 추출, 비교, 검토 상태·의견 저장, 이미지 동일성, 수집 실패 안내, 사설 주소 및 리다이렉트 차단을 검사합니다. 실제 쇼핑몰별 호환성을 보장하지는 않습니다.
